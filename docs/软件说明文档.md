# 软件说明文档

## 产品概述

作品名：无线网络智能诊断助手。英文项目名：WirelessCare。定位：通信学习及小规模网络排查辅助工具。输入为小区级KPI，输出为候选诊断、数据证据、排查和优化建议。本版本是AI辅助开发原型，需团队审查及验证。

## 安装与环境

安装Python 3.10及以上，执行 `python -m pip install -r requirements.txt`，再执行 `python run.py`。实测环境仅Python 3.12.14、numpy 2.3.5和scikit-learn 1.8.0。服务默认绑定127.0.0.1:8787，浏览器打开该地址。Windows、Linux提供启动脚本，但Windows操作系统本身尚未实测。提供可安装源码包，不依赖在线演示地址。

## 输入字段

|字段|单位/格式|校验范围|
|---|---|---|
|timestamp|ISO 8601时间|可解析时间戳|
|cell_id|小区ID|1–64字符|
|rsrp_dbm|dBm|-160至-30|
|sinr_db|dB|-30至60|
|prb_pct|百分比|0至100|
|drop_pct|百分比|0至100|
|latency_ms|ms|0至10000|
|throughput_mbps|Mbps|0至10000|

UTF-8，允许BOM。上限2MB及5000行。同一小区同一时间不得重复。数值不得为空、NaN、Inf。百分比按0–100填写，例如掉线率2%填写2而不是0.02。当前不推断计数器分母，原始计数器需先转换。额外label列不进入预测。

## 操作流程

点击载入演示数据，或选择自己的CSV。点击开始诊断，查看四项摘要。选择小区与指标观察趋势，点击记录查看证据。异常列表最多显示前300条，下载JSON和Markdown包含全部记录。下方可输入问题。API未配置时返回离线证据汇总，不能进行通用语义问答。对全部指标正常却模型异常的记录保留待核实状态。

## 输出与处理边界

随机森林给出分类候选及未校准概率，孤立森林给出偏离正常分布的异常标记。最终诊断结合启发式证据，不等同于已确认根因。知识库提供人工排查步骤及复测指标。没有自动网络配置、发射功率变更或保证性能改善功能。

## 存储与故障处理

数据仅缓存在服务内存，最多8次分析，重启清空。旧报告过期需重新分析。缺少字段、数据越界等返回400并在网页显示原因。大模型调用超时或失败时保留诊断结果。文件名、小区ID及回答以textContent显示，避免HTML注入。默认仅用于本机，当前没有用户登录、TLS终止或多租户隔离，开放公网前需增加鉴权和访问控制。
