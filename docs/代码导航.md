# 完整代码导航

这是能够独立启动的完整Python与Web项目。请在包含run.py的目录运行命令，不能只打开frontend/index.html代替启动服务。

## 先读哪几个文件

| 顺序 | 文件 | 用途 |
| --- | --- | --- |
| 1 | README.md | 项目状态、安装、使用、材料入口 |
| 2 | run.py | HTTP服务、API路由、缓存、导入与导出入口 |
| 3 | backend/engine.py | CSV校验、合成训练数据、随机森林、孤立森林、阈值证据和知识库 |
| 4 | backend/llm.py | 本地配置、环境变量、离线说明、大模型请求与失败处理 |
| 5 | frontend/index.html | 中文工作台页面结构 |
| 6 | frontend/app.js | 文件导入、分析请求、趋势图、问答、报告与JSON下载 |
| 7 | frontend/style.css | 页面样式和移动尺寸适配 |

## Windows快速启动

安装Python 3.12并添加到PATH，在项目根目录打开命令提示符：

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run.py
```

浏览器打开 http://127.0.0.1:8787 ，导入demo_data/demo_kpi.csv。

真实API配置和检查使用同一个虚拟环境：

```bat
.venv\Scripts\python scripts\configure_llm.py
.venv\Scripts\python scripts\check_llm.py
```

检查结果保存在outputs/llm_check.json。未配置不会生成真实调用成功记录。API Key不发聊天、不上传GitHub；.env和llm_config.json已排除。

## 数据怎样经过程序

用户导入CSV → run.py接收 → engine.py校验与分析 → 网页显示证据和趋势。用户提问时，llm.py根据配置调用模型或明确输出离线知识库说明。报告导出保留输入哈希及证据编号。

模型分类是候选原因，当前合成实验不能证明真实网络准确率。项目不会直接更改无线网络配置。团队必须实际理解和复核代码，并如实披露AI辅助。
