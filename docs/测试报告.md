# 测试报告

测试日期：2026-10-08。本报告为开发环境内的实际自测，不是第三方检测证明。

## 环境与范围

Python 3.12.14，numpy 2.3.5，scikit-learn 1.8.0。测试CSV校验、推理、知识库、报告、模拟API响应与失败回退。网页另测导入、诊断、图表选择、导出和移动尺寸。未测试真实大模型服务、真实运营商网络、Windows/macOS运行及公网多用户。

## 单元测试

22项通过。完整原始输出见unit_test_log.txt，源代码见tests/test_engine.py及tests/test_llm.py。包含：演示样本数量、缺列、NaN、百分比越界、重复时间、标签不进入预测、BOM、多因素、可重复结果、报告证据、离线标识、API模拟响应、API失败、空文件。追加检查：多小区轮选、空样本、本地配置及环境覆盖、无效配置、API地址校验、请求契约、异常响应、打包排除密钥。所有API响应均为模拟。

## 合成分类实验

训练2000条，测试800条。独立随机种子9088，与训练共用生成机制。随机森林候选分类准确率99.50%，宏平均F1=0.9950。简单阈值基线准确率98.25%。比较对象为模型候选分类，而非真实根因确诊率，也不是整个融合输出的真实场景准确率。生成数据分布较易区分，指标偏高，不能用作实际应用宣传。

## 性能

500条合成记录，连续8次，耗时中位数22.89ms，P95=23.54ms。计时包含生成CSV、解析、模型推理和汇总，不含网络、页面渲染或大模型调用。仅代表本次容器环境，详见metrics.json。

## 原始材料

metrics.json保存分类报告、混淆矩阵、版本与性能；holdout_synthetic.csv包含800条测试特征、合成标签与预测；example_analysis.json及browser_analysis.json记录完整输出。browser_checks.json保存浏览器实际检查结果。

## 实现修正与后续验证

校验阶段直接拒绝缺失与无穷值，避免静默填补。标签列仅允许作为额外字段，不进入特征。多因素不强行压成单根因，模型与证据冲突保留复核。大模型失败保持已有数值分析。待团队补充真实正常基线、告警与标注后，开展跨时间/跨小区评估和概率校准，再检查现场排查价值。
